## Criterio de anonimización

En las copias públicas se ocultaron los siguientes datos del participante:

- nombre del participante;
- firma del participante.

Se conservaron visibles los siguientes campos para mantener la trazabilidad
de la evidencia:

- código del evaluador;
- fecha de la sesión;
- hora de inicio;
- hora de fin;
- lugar / modalidad;
- equipo utilizado;
- fecha real de firma;
- autorizaciones marcadas;
- aplicador responsable.

## Observación

Los documentos originales completos se conservan fuera del repositorio público
como evidencia restringida de respaldo.
