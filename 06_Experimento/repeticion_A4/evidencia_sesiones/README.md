# Evidencia de sesiones de evaluación A4

Esta carpeta reúne la evidencia documental pública y anonimizada correspondiente a las tres sesiones reales de evaluación realizadas el **19/09/2026** para la repetición A4 del experimento del proyecto **Sistema Inteligente de Control y Seguimiento de Terapia Física (SICST)**.

La repetición A4 utiliza **66 requisitos funcionales normalizados**, identificados mediante los códigos `A4-001` a `A4-066`, y tres evaluadores identificados públicamente únicamente como:

- `EVAL-01`
- `EVAL-02`
- `EVAL-03`

La identidad real de los participantes no se publica en este repositorio.

## 3. Consentimientos complementarios

Se incorporan copias **redactadas y anonimizadas** de los tres consentimientos complementarios de la repetición A4.

En las copias públicas se ocultaron los datos identificables del participante, especialmente:

- nombre del participante;
- firma del participante.

Se mantuvieron visibles los datos necesarios para verificar la sesión y su trazabilidad, entre ellos:

- código del evaluador;
- fecha de la sesión;
- hora de inicio;
- hora de fin;
- lugar o modalidad;
- equipo utilizado;
- fecha real de firma;
- autorizaciones marcadas;
- aplicador responsable;
- contenido general del consentimiento.

Los consentimientos registran autorización para el uso académico de las puntuaciones y, según las opciones marcadas en cada documento, la conservación de audio/video como evidencia restringida y la publicación de una copia anonimizada del consentimiento.

Los documentos originales sin redacción, que contienen nombre y firma, **no se publican en este repositorio abierto** y deben conservarse como evidencia restringida para verificación académica cuando corresponda.

## 4. Transcripciones de las sesiones

Las tres transcripciones se incorporan como evidencia complementaria de las sesiones de evaluación.

Cada transcripción fue revisada y organizada usando la numeración canónica de:

```text
A4-001
...
A4-066
```

La referencia utilizada para esa numeración es:

```text
06_Experimento/repeticion_A4/hoja_items_A4_v1.0.csv
```

La normalización de la numeración **no modifica las puntuaciones registradas por los evaluadores** ni crea requisitos nuevos.

### EVAL-01

La transcripción automática original presentó una incidencia de lectura/numeración: algunos contenidos equivalentes a `A4-055` a `A4-059` aparecieron repetidos y la numeración verbal llegó a mostrar valores superiores a 66.

La versión revisada mantiene únicamente los **66 requisitos canónicos** y documenta la incidencia.

Los requisitos `A4-012`, `A4-014` y `A4-044` no pudieron identificarse con certeza en la transcripción automática y se encuentran marcados para cotejo contra el video original, sin inventar respuestas.

### EVAL-02

La transcripción fue uniformada con la misma estructura de 66 requisitos.

El requisito `A4-022` no pudo identificarse con certeza en la transcripción automática y se encuentra señalado para cotejo contra el video original.

### EVAL-03

La transcripción automática registró una repetición del contenido correspondiente a `A4-042`.

La versión revisada conserva `A4-042` una sola vez dentro de la secuencia canónica y documenta la repetición como incidencia de transcripción.

## 7. Privacidad y conservación de originales

Este repositorio público utiliza códigos anonimizados para los evaluadores.

No deben publicarse aquí:

- nombres reales de los evaluadores;
- firmas;
- cédulas;
- teléfonos;
- correos personales;
- rostros identificables;
- audio o video identificable sin la protección definida para evidencia restringida.

Las copias públicas de los consentimientos se mantienen redactadas. Los originales completos y los archivos audiovisuales originales deben conservarse como evidencia restringida y separada del repositorio público.

---

## 8. Integridad y trazabilidad

Las evidencias de esta carpeta tienen como finalidad permitir la trazabilidad entre:

```text
consentimiento
→ sesión realizada
→ transcripción
→ hoja Excel completada
→ análisis de fiabilidad A5
```

No se reescribe el historial Git para ocultar incidencias. Las correcciones posteriores se incorporan mediante commits nuevos y se documentan en:

```text
07_Datos/registro_correcciones.md
```

Las transcripciones revisadas no deben presentarse como sustitutas del archivo audiovisual original cuando exista una duda que solo pueda resolverse escuchando o visualizando la sesión.
