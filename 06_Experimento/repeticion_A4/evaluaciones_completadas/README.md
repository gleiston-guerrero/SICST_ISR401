# Evaluaciones completadas — repetición A4

Esta carpeta contiene las tres hojas de evaluación reales obtenidas durante la repetición prospectiva A4 del experimento humano frente a LLM.

## Archivos

- `SICST_A4_Evaluador_01_COMPLETADO.xlsx` — evaluador `EVAL-01`
- `SICST_A4_Evaluador_02_COMPLETADO.xlsx` — evaluador `EVAL-02`
- `SICST_A4_Evaluador_03_COMPLETADO.xlsx` — evaluador `EVAL-03`

Cada evaluador calificó los mismos 66 requisitos normalizados y aleatorizados en cinco dimensiones de calidad.

Las plantillas en blanco utilizadas antes de la recolección se conservan en la carpeta padre `06_Experimento/repeticion_A4/` como evidencia de precolección.

Los nombres reales de los evaluadores no se publican en esta carpeta. La identificación se mantiene mediante los códigos anonimizados `EVAL-01`, `EVAL-02` y `EVAL-03`.

Las puntuaciones registradas en estos archivos corresponden a las respuestas proporcionadas durante las sesiones reales de evaluación y no deben modificarse retroactivamente.
